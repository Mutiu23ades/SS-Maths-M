Topic 61: Differentiation and Its Applications

Meaning of Differentiation

Differentiation is a branch of Mathematics known as Calculus. It is used to study how one quantity changes in relation to another quantity.

For example, if distance changes with time, differentiation can help us determine the speed or velocity of an object.

Differentiation is also used to find the gradient of a curve and to solve maximum and minimum problems.

Notation

If y depends on x, the derivative of y with respect to x is written as:

dy/dx

It can also be written as:

f'(x)

The Power Rule

If y = xⁿ, then dy/dx = nxⁿ⁻¹

The power of x is brought down as a coefficient and the power is reduced by one.

Worked Example 1

Differentiate:

y = x⁵

dy/dx = 5x⁴

Answer = 5x⁴

Worked Example 2

Differentiate:

y = 3x⁴

dy/dx = 3 × 4x³

dy/dx = 12x³

Differentiating Several Terms

When an expression contains several terms, differentiate each term separately.

Worked Example 3

Differentiate:

y = 2x⁴ + 5x² - 3x + 7

dy/dx = 8x³ + 10x - 3

The derivative of the constant 7 is zero.

Application: Finding Gradient

The derivative of a curve gives its gradient at a particular point.

Worked Example 4

Find the gradient of y = x² at x = 4.

dy/dx = 2x

At x = 4:

dy/dx = 2(4)

= 8

Remember:

The derivative of a constant is always zero.

Practice Questions

  1. Differentiate x⁶.
  2. Differentiate 4x³.
  3. Differentiate 5x⁴ + 2x.
  4. Differentiate 7x - 9.
  5. Find the gradient of y = x² at x = 6.

Answers

1. 6x⁵
2. 12x²
3. 20x³ + 2
4. 7
5. 12

Topic 62: Integration and Its Applications

Meaning of Integration

Integration is the reverse process of differentiation. It is another major part of Calculus.

Integration can be used to find accumulated quantities and areas under curves.

The Basic Rule of Integration

∫xⁿ dx = xⁿ⁺¹/(n + 1) + C

The power is increased by one and the result is divided by the new power.

Constant of Integration

The letter C is called the constant of integration.

Worked Example 1

Integrate:

∫x² dx

Increase the power:

x³

Divide by 3:

x³/3 + C

Worked Example 2

Integrate:

∫6x² dx

= 6(x³/3)

= 2x³ + C

Integration of Several Terms

Worked Example 3

Integrate:

∫(4x² + 6x + 5)dx

= 4x³/3 + 3x² + 5x + C

Answer = 4x³/3 + 3x² + 5x + C

Applications of Integration

  • Finding areas under curves.
  • Finding accumulated quantities.
  • Solving problems in Physics and Engineering.

Practice Questions

  1. Integrate x⁴.
  2. Integrate 5x².
  3. Integrate 2x + 4.
  4. Integrate 10.
  5. State one application of integration.

Answers

1. x⁵/5 + C
2. 5x³/3 + C
3. x² + 4x + C
4. 10x + C
5. Finding area under a curve.

Topic 63: Coordinate Geometry of Straight Lines

Introduction

Coordinate Geometry studies geometrical shapes using numbers and algebra. A straight line can be represented by an equation.

Gradient of a Straight Line

The gradient tells us how steep a line is.

m = (y₂ - y₁)/(x₂ - x₁)

Worked Example 1

Find the gradient between (1, 2) and (3, 8).

m = (8 - 2)/(3 - 1)

= 6/2

= 3

Equation of a Straight Line

y = mx + c

Where m is the gradient and c is the y-intercept.

Worked Example 2

Write the equation of a line with gradient 4 and y-intercept 2.

y = 4x + 2

Answer: y = 4x + 2

Equation Through a Point

y - y₁ = m(x - x₁)

Worked Example 3

Find the equation of a line with gradient 2 passing through (1, 3).

y - 3 = 2(x - 1)

y - 3 = 2x - 2

y = 2x + 1

Parallel and Perpendicular Lines

  • Parallel lines have equal gradients.
  • The product of gradients of perpendicular lines is -1.

Practice Questions

  1. Find the gradient between (2, 3) and (4, 9).
  2. Write the equation of a line where m = 5 and c = 1.
  3. Find the equation of a line with m = 3 passing through (0, 4).
  4. What is the relationship between gradients of parallel lines?
  5. If one gradient is 4, find the gradient of a perpendicular line.

Answers

1. 3
2. y = 5x + 1
3. y = 3x + 4
4. They are equal.
5. -1/4

Topic 64: Statistics – Measures of Dispersion

Meaning of Dispersion

Measures of dispersion describe how data values are spread out.

They help us understand whether values are close together or widely spread.

Range

Range = Highest Value - Lowest Value

Worked Example 1

Find the range of:

3, 7, 9, 12, 15

Range = 15 - 3

= 12

Variance

Variance measures the average of the squared deviations of values from their mean.

Standard Deviation

Standard deviation measures how far values normally spread from the mean.

Standard Deviation = √Variance

Worked Example 2

Compare the ranges of the following sets:

A: 4, 5, 6, 7, 8

B: 1, 5, 8, 10, 15

Range A = 8 - 4 = 4

Range B = 15 - 1 = 14

Therefore, Set B has a greater spread.

Practice Questions

  1. Find the range of 2, 5, 8, 10, 16.
  2. What does dispersion measure?
  3. State the formula for range.
  4. What is the relationship between variance and standard deviation?
  5. Which data set is more spread out: one with range 4 or range 10?

Answers

1. 14
2. The spread of data.
3. Highest value - Lowest value.
4. Standard deviation is the square root of variance.
5. The set with range 10.
